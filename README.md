# ♞ Chess Lens

Play bots (400–1800), solve ~2,900 rated puzzles, practise your own mistakes, and analyse games with every move rated:
**Brilliant · Great · Good · Inaccuracy · Mistake · Blunder**.

Built with React + Vite, chess.js and Stockfish (runs fully in the browser).

```bash
npm install
npm run dev
```

Deploys to GitHub Pages automatically on every push to `main`.

Puzzles come from the [Lichess puzzle database](https://database.lichess.org/#puzzles) (CC0).
